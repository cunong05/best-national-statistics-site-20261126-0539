StatAtlas is a national statistics explorer: population, economy, health and demography for 12 countries, from World Bank data, with the source and year on every figure. Look a country up, rank all twelve by any indicator, or compare any three side by side — with ten-year population and GDP charts on every country page. It runs entirely from its own files, on a desktop and on a phone, with nothing fetched from another origin.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. `main.ts` hands the site in: it copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json` (run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`).
